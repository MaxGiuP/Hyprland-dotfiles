# Dynamic wallpaper set

This coherent landscape is colour-graded into four time-of-day states so the
Quickshell Material palette does not jump between unrelated images:

- `morning`: warm ivory/cream, approximately 4300 K
- `day`: neutral cool white, approximately 6500 K
- `evening`: subdued amber/orange, approximately 2800 K
- `night`: low-luminance blue-black with no bright focal point

The images were generated with OpenAI's built-in image generation tool and are
intended for the sunrise/sunset-aware rotator in
`dotfiles/.config/quickshell/ii/scripts/colors/dynamic_wallpaper.py`.
